# RentNote 桌面卡片（Form Widget）实现计划

## Goal

为 RentNote（租房台账）应用添加桌面服务卡片功能，让用户无需打开 App 即可在桌面查看本月租金和最近到期信息，并支持快捷添加房源。

## Scope / Non-goals

**包含：**
- 创建 `FormExtensionAbility`（EntryFormAbility）
- 创建 `form_config.json` 卡片配置
- 改造已有 `WidgetCard.ets` 为动态卡片页面（使用 `@Entry` + `@Component`，通过 `@StorageProp` 接收数据）
- 在 `module.json5` 注册 extensionAbilities
- 添加必要的字符串资源
- 卡片点击跳转回 App 主页

**不包含：**
- 多尺寸卡片（仅实现 2×4 一种规格，与现有 WidgetCard 350×160 设计一致）
- 卡片定时刷新的数据持久化（当前 Repository 是内存 Mock，定时刷新返回当前内存数据即可）
- 深色模式适配
- FormId 持久化存储管理（首期简化实现）

## Current State And Constraints

| 现状 | 说明 |
|------|------|
| `WidgetCard.ets` 已存在 | 位于 `components/` 目录，是一个纯 UI 组件，硬编码数据，`@Component` 装饰 |
| 无 `FormExtensionAbility` | 整个项目没有 FormExtension 实现文件 |
| 无 `form_config.json` | resources/profile/ 中不存在卡片配置 |
| `module.json5` 无 extensionAbilities | 未注册 form 扩展 |
| `PropertyRepository` 是内存 Mock | 数据不持久，卡片刷新只能获取当前内存数据 |
| ArkTS 卡片约束 | 卡片中不能导入共享包、不能用 `@State`（需用 `@StorageProp`）、不支持 `setTimeout`、不能访问网络 |

**关键 ArkTS 卡片约束：**
1. 卡片页面必须用 `@Entry` + `@Component` 装饰（不能用 `@ComponentV2`）
2. 数据必须通过 `@StorageProp` 从 `FormExtensionAbility` 的 `formBindingData` 读取
3. 卡片中不能直接导入项目的 Repository/ViewModel（卡片运行在受限沙箱），数据由 FormExtensionAbility 提供
4. 点击交互必须用 `postCardAction`，不能用 `NavPathStack` 或 `router`
5. 卡片 UI 组件有限制，`Shadow` 的 `shadow` 接口在卡片中可能受限

## Design

### 整体架构

```
用户添加卡片 → 系统调用 EntryFormAbility.onAddForm()
                         ↓
               从 PropertyRepository 读取数据
                         ↓
               通过 formBindingData 返回 formData
                         ↓
               系统渲染 WidgetCard 页面（@StorageProp 读取数据）
                         ↓
               用户点击卡片 → postCardAction 跳转回 App
```

### 1. form_config.json

创建 [entry/src/main/resources/base/profile/form_config.json](entry/src/main/resources/base/profile/form_config.json)：

```json
{
  "forms": [
    {
      "name": "RentWidget",
      "displayName": "租房台账",
      "description": "显示本月租金和到期提醒",
      "src": "./ets/widget/pages/RentWidgetCard.ets",
      "uiSyntax": "arkts",
      "window": {
        "designWidth": 720,
        "autoDesignWidth": true
      },
      "colorMode": "auto",
      "isDynamic": true,
      "isDefault": true,
      "updateEnabled": true,
      "scheduledUpdateTime": "10:00",
      "updateDuration": 1,
      "defaultDimension": "2*4",
      "supportDimensions": ["2*4"]
    }
  ]
}
```

**说明：**
- `isDynamic: true`：动态卡片，支持交互和数据更新
- `src`：指向新创建的卡片页面文件（从 components/ 独立出来，放在 widget/ 目录下）
- 仅支持 2×4 尺寸（与 350×160 设计稿匹配）
- 定时更新：每天 10:00 更新一次

### 2. EntryFormAbility.ets

创建 [entry/src/main/ets/widget/EntryFormAbility.ets](entry/src/main/ets/widget/EntryFormAbility.ets)：

```typescript
import { FormExtensionAbility, formBindingData, formInfo } from '@kit.FormKit';
import { Want } from '@kit.AbilityKit';
import { PropertyRepository } from '../repository/PropertyRepository';

export default class EntryFormAbility extends FormExtensionAbility {
  onAddForm(want: Want): formBindingData.FormBindingData {
    const formData = this.buildFormData();
    return formBindingData.createFormBindingData(formData);
  }

  onCastToNormalForm(formId: string): void {
    this.updateFormData(formId);
  }

  onUpdateForm(formId: string): void {
    this.updateFormData(formId);
  }

  onRemoveForm(formId: string): void {
    // 卡片被移除，无需处理
  }

  onAcquireFormState(want: Want): formInfo.FormState {
    return formInfo.FormState.READY;
  }

  private buildFormData(): Record<string, Object> {
    const repo: PropertyRepository = new PropertyRepository();
    const overview = repo.getStatisticsOverview();
    const expiring = repo.getExpiringProperties(30);
    const totalRent = overview.monthlyAvgRent * overview.rentingCount;
    const nextExpiry = expiring.length > 0 ? expiring[0].endDate : '';

    return {
      'totalRent': totalRent > 0 ? '¥' + totalRent.toLocaleString() : '暂无',
      'rentLabel': overview.rentingCount > 0 ? '本月租金（' + overview.rentingCount + '套）' : '本月租金',
      'nextExpiry': nextExpiry !== '' ? nextExpiry + ' 到期' : '暂无到期',
      'expiryColor': expiring.length > 0 ? '#F59E0B' : '#9CA3AF'
    };
  }

  private updateFormData(formId: string): void {
    const formData = this.buildFormData();
    const formBindingDataObj = formBindingData.createFormBindingData(formData);
    this.updateForm(formId, formBindingDataObj);
  }
}
```

**关键点：**
- FormExtensionAbility 运行在同一进程，可以直接导入 PropertyRepository
- `onAddForm`：用户添加卡片时调用，返回初始数据
- `onUpdateForm`：系统定时更新时调用
- 数据通过 `formBindingData.createFormBindingData()` 传递，键值对形式
- `PropertyRepository` 每次创建新实例（因为内存 Mock 数据在不同实例间不共享，但如果 Repository 使用了 AppStorageV2 单例，则可共享——当前实现中 FormExtensionAbility 与 UIAbility 在同一进程，AppStorageV2 数据可以共享）

**重要补充：** 由于 PropertyRepository 在 EntryAbility 中通过 `AppStorageV2.connect()` 注册为单例，而 FormExtensionAbility 与 UIAbility 在同一进程，实际上可以尝试通过 `AppStorageV2.connect()` 获取同一个实例。但为了安全起见，如果 AppStorageV2 尚未初始化（如 App 未启动时卡片先被添加），则需要 fallback 创建新实例。因此 buildFormData 中使用 `new PropertyRepository()` 直接创建新实例获取 mock 数据更稳妥。

### 3. RentWidgetCard.ets（卡片页面）

创建 [entry/src/main/ets/widget/pages/RentWidgetCard.ets](entry/src/main/ets/widget/pages/RentWidgetCard.ets)：

将现有 `WidgetCard.ets` 的布局改造为动态卡片页面：

```typescript
import { formBindingData } from '@kit.FormKit';

@Entry
@Component
struct RentWidgetCard {
  @StorageProp('totalRent') totalRent: string = '暂无';
  @StorageProp('rentLabel') rentLabel: string = '本月租金';
  @StorageProp('nextExpiry') nextExpiry: string = '暂无到期';
  @StorageProp('expiryColor') expiryColor: string = '#9CA3AF';

  build() {
    Row() {
      // 左侧：快捷添加按钮
      Column() {
        Text('+')
          .fontSize(32)
          .fontColor('#FFFFFF')
          .fontWeight(FontWeight.Light)

        Text('快捷添加')
          .fontSize(12)
          .fontColor('#FFFFFF')
          .margin({ top: 4 })
      }
      .width(80)
      .height(120)
      .backgroundColor('#5046E5')
      .borderRadius(24)
      .justifyContent(FlexAlign.Center)
      .margin({ left: 16 })
      .onClick(() => {
        postCardAction(this, {
          action: 'router',
          abilityName: 'EntryAbility',
          params: {
            action: 'addProperty'
          }
        });
      })

      // 右侧：租金信息
      Column() {
        Text(this.totalRent)
          .fontSize(32)
          .fontColor('#0F1419')
          .fontWeight(FontWeight.Bold)

        Text(this.rentLabel)
          .fontSize(13)
          .fontColor('#6B7280')
          .margin({ top: 4 })

        Text(this.nextExpiry)
          .fontSize(12)
          .fontColor(this.expiryColor)
          .margin({ top: 6 })
      }
      .layoutWeight(1)
      .height(120)
      .margin({ left: 16 })
      .alignItems(HorizontalAlign.Start)
      .justifyContent(FlexAlign.Center)
      .onClick(() => {
        postCardAction(this, {
          action: 'router',
          abilityName: 'EntryAbility',
          params: {}
        });
      })
    }
    .width('100%')
    .height('100%')
    .backgroundColor('#FFFFFF')
    .borderRadius(16)
    .padding({ right: 16 })
  }
}
```

**关键设计决策：**
- 使用 `@Entry` + `@Component`（不是 `@ComponentV2`），因为卡片不支持 V2 装饰器
- 使用 `@StorageProp` 读取 FormExtensionAbility 传入的数据
- **不导入 DesignTokens**：卡片中导入项目模块存在限制风险，直接使用硬编码颜色/字号值更安全
- **不使用 `.shadow()`**：卡片中 shadow 支持有限，用 `borderRadius` + 纯色背景替代
- 点击"快捷添加"通过 `postCardAction` 跳转回 App，并传递 `addProperty` action
- 点击右侧信息区跳转回 App 主页
- 使用 `width('100%')` + `height('100%')` 让卡片自适应系统分配的尺寸

## Risks And Compatibility

| 风险 | 影响 | 缓解 |
|------|------|------|
| 卡片中导入 PropertyRepository 可能受限 | 编译或运行时报错 | fallback 方案：在 EntryFormAbility 中直接硬编码数据，不导入 Repository |
| 卡片中 `.shadow()` 不可用 | UI 渲染异常 | 设计中已避免使用 shadow，使用纯色背景 |
| App 未启动时卡片先添加，AppStorageV2 单例未初始化 | 卡片数据为空/mock 数据 | buildFormData 中使用 `new PropertyRepository()` 创建新实例，确保有 mock 数据返回 |
| 卡片运行沙箱与主应用隔离 | 数据不同步 | 同一进程下数据共享，定时更新会刷新数据 |
| `@ComponentV2` + `@StorageProp` 在卡片中不兼容 | 编译报错 | 使用 `@Component` + `@StorageProp`（V1 装饰器） |
